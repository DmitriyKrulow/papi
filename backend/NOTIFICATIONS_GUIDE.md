# 📧 Система уведомлений

## Возможности

1. **Email уведомления** — отправка на email пользователя через SMTP
2. **MAX chat уведомления** — отправка через чат MAX по REST API
3. **Внутренние уведомления** — хранятся в БД, доступны в интерфейсе
4. **Массовая рассылка** — отправка выбранным пользователям из админ-панели

## Настройка

### 1. SMTP (Email)

Перейдите в **Админ-панель → Уведомления** и заполните:
- **SMTP хост**: `smtp.gmail.com` (или ваш SMTP)
- **Порт**: `587` (TLS) или `465` (SSL)
- **Логин SMTP**: ваш email
- **Пароль SMTP**: пароль от email (или app password)
- **Отправитель**: `noreply@company.com`

### 2. MAX chat

В той же вкладке заполните:
- **API URL**: `http://localhost:8080/api/notify` (адрес вашего MAX chat)
- **API токен**: токен для авторизации

### 3. MAX ID пользователей

Для каждого пользователя укажите **MAX ID**:
- Перейдите в **Админ-панель → Пользователи**
- Нажмите ✏️ Редактировать
- Поле **MAX ID** — идентификатор пользователя в MAX chat
- Если MAX ID не указан, уведомление через MAX не отправится

## Как отправить уведомление

1. Перейдите в **Админ-панель → Уведомления**
2. В разделе **"Отправить уведомление"**:
   - Введите **Заголовок**
   - Введите **Текст сообщения**
   - Выберите пользователей (или "Выбрать всех")
3. Нажмите **"Отправить"**

Уведомление будет:
- ✅ Сохранено в БД (доступно в разделе "Уведомления" у пользователя)
- ✅ Отправлено на email (если включён SMTP и есть email у пользователя)
- ✅ Отправлено в MAX chat (если включён MAX и указан max_user_id)

## Автоматические уведомления

Уведомления отправляются автоматически при:
- 📋 **Начале инвентаризации** — ответственным лицам
- ✅ **Завершении инвентаризации** — всем участникам
- 🔧 **Создании заявки на ремонт** — ответственным

## API Endpoints

### Получить настройки
```
GET /api/notification-settings/config
Authorization: Bearer <token>
```

### Сохранить настройки
```
POST /api/notification-settings/config
Authorization: Bearer <token>
Body: {
  "smtp_host": "smtp.gmail.com",
  "smtp_port": 587,
  "smtp_user": "email@gmail.com",
  "smtp_password": "password",
  "sender_email": "noreply@company.com",
  "max_api_url": "http://localhost:8080/api/notify",
  "max_api_token": "token",
  "enable_email": true,
  "enable_max": false
}
```

### Отправить уведомление
```
POST /api/notification-settings/send
Authorization: Bearer <token>
Body: {
  "user_ids": [1, 2, 3],  // [] = всем пользователям
  "title": "Заголовок",
  "message": "Текст сообщения",
  "type": "manual"
}
```

### Получить список пользователей
```
GET /api/notification-settings/users
Authorization: Bearer <token>
```

## Переменные в шаблонах

Шаблоны уведомлений поддерживают переменные:
- `{check_name}` — название инвентаризации
- `{found}` — количество найденных
- `{missing}` — количество отсутствующих
- `{asset_name}` — название актива
- `{repair_id}` — номер заявки

## Хранение в БД

Все уведомления сохраняются в таблице `notifications`:
- `user_id` — кому отправлено
- `type` — тип уведомления
- `title` — заголовок
- `message` — текст
- `email_sent` — отправлен ли email
- `max_sent` — отправлено ли в MAX
- `is_read` — прочитано ли
