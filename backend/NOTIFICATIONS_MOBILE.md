# Система уведомлений и мобильная инвентаризация

## 📧 Система уведомлений

### Возможности:
- **Email уведомления** - отправка на email пользователя
- **MAX chat уведомления** - отправка через чат MAX (если настроен)
- **Хранение в БД** - все уведомления сохраняются и доступны в интерфейсе

### Настройка:

#### 1. Email (SMTP):
Добавьте в `.env`:
```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_email@gmail.com
SMTP_PASSWORD=your_app_password
SENDER_EMAIL=your_email@gmail.com
```

#### 2. MAX chat (опционально):
```env
MAX_API_URL=http://localhost:8080/api/notify
MAX_API_TOKEN=your_max_api_token
```

### API Endpoints:

#### Получить уведомления:
```
GET /api/notifications?limit=50&offset=0&type=inventory&unread_only=false
```

#### Получить количество непрочитанных:
```
GET /api/notifications/unread-count
```

#### Отметить как прочитанное:
```
POST /api/notifications/{notification_id}/read
```

#### Отметить все как прочитанные:
```
POST /api/notifications/read-all
```

## 📱 Мобильная инвентаризация через QR-коды

### Принцип работы:
QR-код на активе содержит **ссылку** на мобильную страницу актива. При сканировании камерой телефона открывается страница с данными актива и возможностью подтверждения инвентаризации.

### Маршруты:
- **Список активов пользователя**: `/inventory-mobile` (требует авторизации)
- **Просмотр актива**: `/inventory/asset/:assetId` (публичный доступ для просмотра, авторизация для подтверждения)

### Как работает:

1. **Генерация QR-кода** (в маркировке):
   - При создании бирки для актива, система генерирует QR-код
   - QR-код содержит ссылку вида:
   ```
   http://localhost:5173/inventory/asset/123
   ```
   - QR-код встраивается в HTML-шаблон бирки
   - Бирка печатается с QR-кодом

2. **Сканирование QR-кода**:
   - Пользователь открывает камеру телефона
   - Сканирует QR-код на активе
   - Телефон автоматически открывает ссылку в браузере

3. **Страница актива**:
   - Загружаются данные актива (название, модель, серийный номер и т.д.)
   - Показываются существующие фотографии
   - Если есть активная инвентаризация, появляются кнопки подтверждения

4. **Подтверждение наличия**:
   - **"Найден"** - актив отмечается как присутствующий
   - **"Отсутствует"** - актив отмечается как отсутствующий
   - Можно загрузить новое фото с текущего состояния

5. **Загрузка фото**:
   - Кнопка "Добавить фото" открывает камеру или выбор файла
   - Фото загружается на сервер и привязывается к активу
   - Фото отображается в галерее актива

### Преимущества подхода:
- ✅ Не нужно специальное приложение - работает в любом браузере
- ✅ QR-код встраивается в бирку при печати
- ✅ Используется стандартная камера телефона
- ✅ Можно делиться ссылками на активы
- ✅ Можно работать офлайн (кэширование данных)

### API Endpoints для мобильной инвентаризации:

#### Получить данные актива:
```
GET /api/assets/:assetId
```

#### Получить активную инвентаризацию:
```
GET /api/inventory-checks/active
```

#### Подтвердить наличие актива:
```
POST /api/inventory-checks/:checkId/confirm/:assetId?found=true|false
```

#### Загрузить фото актива:
```
POST /api/assets/:assetId/photos
Content-Type: multipart/form-data
Body: photo (file), category, description
```

#### Получить HTML бирки с QR-кодом:
```
GET /api/marking/label-html/:assetId
Response: {
  "html": "...",
  "inventory_number": "INV-001",
  "qr_url": "http://localhost:5173/inventory/asset/123"
}
```

## 🔔 Уведомления об инвентаризации

### Когда отправляются:
1. **При старте инвентаризации** - ответственному лицу и создателю
2. **При завершении инвентаризации** - всем участникам
3. **При изменении статуса** - при отмене или обновлении

### Кому отправляются:
- **Ответственному лицу** (responsible_id)
- **Создателю инвентаризации** (created_by)

## 🔧 Интеграция с бэкендом

### Новые модели БД:
- `notifications` - таблица уведомлений

### Новые сервисы:
- `NotificationService` - отправка email и MAX уведомлений

### Новые endpoints:
- `GET /api/inventory-checks/my-assets` - список активов пользователя
- `GET /api/notifications` - список уведомлений
- `GET /api/notifications/unread-count` - счетчик непрочитанных
- `POST /api/notifications/{id}/read` - отметить как прочитанное
- `POST /api/notifications/read-all` - отметить все как прочитанные

### QR-коды в маркировке:
- `GET /api/marking/label-html/:assetId` - получение HTML бирки с QR-кодом
- `GET /api/marking/label-batch?asset_ids=1,2,3` - пакетная генерация бирок с QR-кодами

## 📊 Примеры использования

### Отправка уведомления:
```python
from src.core.services.notification_service import NotificationService

service = NotificationService()
service.send_email("user@example.com", "Заголовок", "Тело сообщения")
service.send_max_notification(user_id=1, title="Заголовок", message="Сообщение")
service.send_inventory_notification(user, inventory_check, asset)
```

### Получение уведомлений пользователя:
```typescript
const token = localStorage.getItem('token');
const response = await fetch('/api/notifications?unread_only=true', {
  headers: { 'Authorization': `Bearer ${token}` }
});
const notifications = await response.json();
```

### Подтверждение наличия актива:
```typescript
const response = await fetch(
  `/api/inventory-checks/${checkId}/confirm/${assetId}?found=true`,
  {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${token}` }
  }
);
```

### Получение HTML бирки с QR-кодом:
```typescript
const token = localStorage.getItem('token');
const response = await fetch(`/api/marking/label-html/${assetId}`, {
  headers: { 'Authorization': `Bearer ${token}` }
});
const data = await response.json();
// data.html - HTML-код бирки с QR-кодом
// data.qr_url - URL для мобильного доступа к активу
```

## 📱 Пример бирки с QR-кодом

QR-код встраивается в HTML-шаблон бирки:
```html
<div class="label" style="width: 105mm; height: 37mm;">
  <!-- Логотип компании -->
  <div style="text-align: center;">ООО «ПАО»</div>
  
  <!-- Информация об активе -->
  <div>Ноутбук Dell Latitude</div>
  <div>Инв. №: INV-001</div>
  <div>Отв: Иванов И.И.</div>
  
  <!-- QR-код -->
  <div style="text-align: center;">
    <img src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..." style="width: 20mm; height: 20mm;" />
    <div style="font-size: 5pt;">INV-001</div>
  </div>
</div>
```

При сканировании этой ссылки пользователь попадает на страницу актива, где может:
1. Просмотреть все данные об активе
2. Увидеть существующие фотографии
3. Загрузить новое фото
4. Подтвердить наличие ("Найден" или "Отсутствует") - требуется авторизация

## 🖨️ Печать бирок

### Процесс:
1. Перейдите в раздел **Маркировка**
2. Выберите активы для печати
3. Нажмите **"Просмотр"** для одиночной печати или **"Пакетная печать"** для нескольких
4. В предпросмотре вы увидите бирки с QR-кодами
5. Нажмите **"Печать"** для отправки на принтер

### Настройки печати:
- Размер бирки: 105x37mm (стандарт) или кастомный
- Количество колонок: 3 (стандарт)
- Логотип компании: загружается через настройки
- QR-код: автоматически генерируется для каждого актива

### QR-код на бирке:
- Содержит ссылку на мобильную страницу актива
- Под QR-кодом отображается инвентарный номер
- Можно сканировать камерой телефона для быстрого доступа
